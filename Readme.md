# Obfuscate

`obfuscate`  is a CLI command to create a Swift file you can use in an app that obfuscates the input. Typically, the input is an API secret key.

This method of obfuscating secrets was based on a blog post at [NSHipster](https://nshipster.com/secrets/)

The command will print the output to the console, which you can copy, or, optionally, to a file in the current working directory.

Either way, you then have a file that produces a `Secrets` enum, which allows you to retrieve the original API key without having the key anywhere in your source control system. It is also not directly within the `Secrets` file.

> [!IMPORTANT]
> This is **not** high-tech encryption. It's merely obfuscation. If *anyone* wants to crack this, it's trivially easy to do so. It just means they have to be motivated enough to do *some* work, rather than have the keys in plain sight.

> [!NOTE]
> Each time the command is run, it will produce different output, because it generates a random seed for the encoding/decoding process.

## Installation

Obfuscate can be easily installed via Homebrew, an optional package manager:

```bash
brew install --build-from-source obfuscate
```

## Usage

```bash
obfuscate <secretAPIkey>
```
returns 
```swift
import Foundation
import Playgrounds

// Secrets.swift

/// `Secrets` lets us obfuscate secrets, such as API keys, without committing the actual keys to source control
///
/// This enum was generated by the in-house CLI tool `obfuscate`, and should not be altered. See `obfuscate -h` for more info on the tool
///
/// - Note: This method of obfuscating secrets was based on a blog post at [NSHipster](https://nshipster.com/secrets/)
///
/// - Important: This is **not** high-tech encryption. It's merely obfuscation. If *anyone* wants to crack this, it's trivially easy to do so. It just means they have to be motivated enough to do *some* work, rather than have the keys in plain sight.
enum Secrets {
    private static let salt: [UInt8] = [
        0x0B, 0x4B, 0xFA, 0xC1, 0xA6, 0x26, 0xE5, 0x00
    ]
    
    // Key for secretAPIkey
    static var apiKey1: String {
    let encoded: [UInt8] = [
        0x78, 0x2E, 0x99, 0xB3, 0xC3, 0x52, 0xA4, 0x50, 0x42, 0x20, 0x9F, 0xB8
    ]

    return decode(encoded, secret: salt)
}

    static func decode(_ encoded: [UInt8], secret: [UInt8]) -> String {
        let decodedBytes = encoded.enumerated().map { index, byte in
            byte ^ secret[index % secret.count]
        }
        
        return String(bytes: decodedBytes, encoding: .utf8) ?? ""
    }
}


#Playground("Check API Coding") {
let check1 = Secrets.apiKey1

}
```
